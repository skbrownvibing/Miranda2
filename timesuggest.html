TimeSuggest

Read your Google Calendar. Spit out free slots in a format you can paste into an email.

First-time setup

You need a Google OAuth Client ID. One-time setup, ~5 minutes:

  1. Go to Google Cloud Console and create (or pick) a project.
  2. Enable the Google Calendar API (APIs & Services → Library).
  3. Configure the OAuth consent screen as "External", add your Google email under "Test users".
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins add the URL where you'll open this page (e.g. http://localhost or your Vercel URL). No redirect URI needed.
  6. Copy the Client ID below.
